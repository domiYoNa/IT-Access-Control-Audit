# IT Access Control Audit

## Technology Audit Portfolio Project

A beginner-level Technology Audit project focused on reviewing user access controls, identifying potential security risks, performing control testing, and documenting audit findings.

> **Note:** This project uses completely fictional data for educational and portfolio purposes.

---

## 🎯 Project Objective

The objective of this project is to simulate an IT access-control audit and evaluate whether basic access-management controls are operating appropriately.

The audit focuses on:

- User account lifecycle
- Privileged access
- Multi-Factor Authentication (MFA)
- Risk identification
- Audit findings
- Remediation recommendations
